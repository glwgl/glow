GLOW: как получить программу (файл .exe)
=========================================

Glow показывает вверху экрана «остров»: что играет сейчас (с текстом песни
в такт), заряд батареи и погоду, календарь и таймер Pomodoro.

Готовый .exe собирает за тебя GitHub. Ничего ставить на компьютер не нужно.
Нужен только бесплатный аккаунт на github.com.

ШАГ 1. Создай репозиторий
  - Зайди на github.com и войди в аккаунт.
  - Нажми «+» вверху справа, затем «New repository».
  - Назови его glow, оставь Public, нажми «Create repository».

ШАГ 2. Загрузи файлы
  - Распакуй glow-app.zip.
  - На странице репозитория нажми «uploading an existing file».
  - Открой распакованную папку glow-app, выдели ВСЁ её содержимое
    и перетащи в окно браузера.
  - Обязательно должна загрузиться скрытая папка .github. Если её не видно,
    в Проводнике включи Вид, Показать, Скрытые элементы.
  - Нажми «Commit changes».

ШАГ 3. Запусти сборку
  - Открой вкладку «Actions».
  - Слева выбери «Сборка установщика», справа нажми «Run workflow»,
    затем зелёную кнопку «Run workflow».
  - Если GitHub просит включить workflows, подтверди.
  - Жди 5-10 минут, пока рядом с запуском не появится зелёная галочка.

ШАГ 4. Скачай установщик
  - Вернись на главную страницу репозитория.
  - Справа нажми «Releases».
  - Скачай файл Glow_0.1.0_x64-setup.exe.

ШАГ 5. Установи
  - Открой скачанный .exe. Права администратора не нужны.
  - Если Windows показала синее окно SmartScreen, нажми «Подробнее»,
    затем «Выполнить в любом случае». Так бывает, потому что файл
    не подписан платным сертификатом.
  - Нажимай «Далее» и оставь галочку «Запустить Glow».
  - WebView2 установится сам, если его нет в системе.

УПРАВЛЕНИЕ
  - Колесо мыши или свайп по острову: переключить режим.
  - Стрелки влево и вправо (когда остров в фокусе): переключить режим.
  - Клик по острову: свернуть и развернуть.
  - Правый клик по острову: закрыть Glow.

ТЕКСТ ПЕСНИ
  - Текст ищется автоматически по исполнителю и названию трека.
  - Если не найден, нажми кнопку с папкой и выбери свой файл .lrc.

ПОГОДА
  - В файле src/index.html найди строку WEATHER=[52.37,4.90] и впиши
    широту и долготу своего города.

ЕСЛИ СБОРКА ЗАВЕРШИЛАСЬ КРАСНЫМ КРЕСТИКОМ
  - Открой этот запуск во вкладке Actions, скопируй текст ошибки
    и покажи его тому, кто помогает с проектом.

СБОРКА НА СВОЁМ КОМПЬЮТЕРЕ (по желанию)
  - Установи Rust (rustup.rs) и Node.js, затем в папке проекта:
      npm install
      npm run dev      (запуск для проверки)
      npm run build    (сборка установщика)
